# VELOR — Independent Wardrobe

Projeto inicial da loja VELOR, desenvolvido com React, Vite, GSAP e Lucide React.

## Como executar

```bash
npm install
npm run dev
```

## Como gerar a versão de produção

```bash
npm run build
```

A pasta `dist` será criada pelo Vite.

## Publicar na Vercel

1. Importe este repositório na Vercel.
2. Framework preset: Vite.
3. Build command: `npm run build`.
4. Output directory: `dist`.

## Observações

- O catálogo e o carrinho são demonstrações front-end. Ainda não há gateway de pagamento, estoque ou gestão de pedidos.
- As fotografias iniciais usam imagens remotas do Unsplash. Substitua-as por fotografias licenciadas da marca antes de uma operação comercial.
- O formulário de newsletter é demonstrativo e precisa ser conectado a um serviço de e-mail.
